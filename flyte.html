About

Flyte is an augmented reality app that overlays real-time labels on landmarks, addresses, and points of interest through your camera. Point your phone at the horizon and see what's there — works online via OpenStreetMap and offline with cached data.

Features

  • AR Landmark Labels — See names of landmarks overlaid in real time
  • Address Lookup — Point your camera at a building to see its address
  • POI Discovery — Find nearby points of interest by category
  • Online & Offline — Live OSM queries online, cached tiles + local DB offline
  • Compass & Gyro — Uses device sensors for precise overlay positioning
  • No API Key Required — Everything runs on free OpenStreetMap infrastructure

Tech Stack

  • Kotlin + Android SDK
  • CameraX for camera pipeline
  • Custom Canvas View for AR overlay
  • osmdroid for online/offline maps
  • OpenStreetMap Nominatim + Overpass API
  • FusedLocationProvider for GPS
  • Room Database for offline POI cache
